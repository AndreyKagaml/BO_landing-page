# Bang & Olufsen Landing Page

A modern, fully responsive landing page inspired by **Bang & Olufsen**, a premium audio and home entertainment brand. The website showcases the brand's products, highlights key product categories, and presents its design philosophy through a clean and elegant user interface.

## Technologies Used

The project is built using modern front-end technologies and development tools:

- **HTML5:** Semantic markup for a clear and accessible page structure.
- **CSS3 (SCSS/SASS):** Modular stylesheets, variables, mixins and nested rules for maintainable CSS.
- **Parcel:** Bundler used to compile and serve the project during development and production builds.
- **Stylelint & ESLint:** Code quality tools used to maintain consistent styling and prevent basic JavaScript errors.

---

## Features

- **Responsive Design:** Adaptive layout optimized for mobile, tablet and desktop screens.
- **Hero Section:** Eye-catching introductory section showcasing the brand's identity.
- **Product Showcase:** Recommended products displayed with images, descriptions and prices.
- **Product Categories:** Dedicated sections for portable speakers, earphones and smart home products.
- **Interactive Navigation:** Mobile navigation menu with smooth transitions.
- **About Us Section:** Information about Bang & Olufsen and its design philosophy.

## Getting Started

Follow these instructions to run the project locally.

### 1\. Clone the repository

Open your terminal and execute the following commands:

```bash
git clone https://github.com/AndreyKagaml/BO_landing-page.git
cd BO_landing-page
```

### 2\. Install dependencies

Install all required packages:

```bash
npm install
```

### 3\. Run the project locally

Install all required packages:

```bash
npm install
# or
yarn install
```

### 4\. Run the project locally

Start the local development server:

```bash
npm start
# or
yarn start
```
